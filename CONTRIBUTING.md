# Contributing

Спасибо за интерес к проекту **Lyrics Video Generator**.

## Локальный запуск проекта

### 1) Подготовка окружения

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Для полного функционала авто-синхронизации:

```bash
pip install -r requirements.txt -r requirements-autosync.txt
```

Убедитесь, что в системе доступны `ffmpeg` и `ffprobe`.

### 2) Запуск приложения

```bash
python main.py
```

## Стиль pull request

Чтобы PR было легко ревьюить, пожалуйста:

- Делайте небольшие, сфокусированные изменения (одна задача — один PR).
- Давайте понятный заголовок PR в формате: `type: краткое описание` (например, `fix: improve lyrics timing validation`).
- В описании PR указывайте:
  - контекст/проблему;
  - что именно изменено;
  - как это проверить локально;
  - возможные ограничения и edge cases.
- Если меняется UI, прикладывайте скриншоты/гиф.
- Обновляйте документацию (`README.md`, этот файл и т.д.), если меняется поведение пользователя.

## Минимальные требования к тестам

Перед отправкой PR выполните минимум:

```bash
python -m compileall .
pytest
```

Если изменения затрагивают только документацию, достаточно убедиться, что markdown-файлы корректны и ссылки актуальны.

Если изменения затрагивают рендер, синхронизацию или валидацию, добавьте/обновите тесты в `tests/` для новых сценариев.
