# Lyrics Video Generator

Desktop GUI-приложение (PySide6) для генерации вертикальных lyric-video (9:16) по аудиотреку.

## Возможности MVP

- Загрузка аудио и обложки.
- Ввод исполнителя, названия, даты релиза.
- Таблица строк: `время старта (мм:сс) + текст`.
- Валидация входных данных.
- Извлечение доминирующих цветов из обложки (KMeans).
- Генерация мягкого анимированного фона на основе палитры.
- Построчная синхронизация текста по времени старта.
- Экспорт MP4 (H.264 + AAC), длительность по длительности трека.
- Подробные логи в консоль по шагам обработки.

## Структура

- `gui/` — окно приложения и запуск рендера.
- `models/` — модели данных проекта.
- `core/audio.py` — чтение длительности через `ffprobe`.
- `core/image_analysis.py` — извлечение палитры из обложки.
- `core/background.py` — генерация кадров мягкого фона.
- `core/layout.py` — геометрия композиции кадра.
- `core/lyrics.py` — парсинг/сортировка таймингов, активная строка.
- `core/validation.py` — валидация проекта.
- `core/render.py` — рендер и muxing через `ffmpeg`.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Также в системе должны быть установлены `ffmpeg` и `ffprobe`.

### Если на Windows ошибка `WinError 2`
Это почти всегда означает, что не найден `ffmpeg` или `ffprobe` в `PATH`.
Установите FFmpeg и добавьте путь к бинарникам (`ffmpeg.exe`, `ffprobe.exe`) в системную переменную `PATH`.

## Запуск

```bash
python main.py
```

## Как пользоваться

1. Выберите аудиофайл.
2. Выберите изображение обложки.
3. Заполните метаданные (исполнитель, название, дата).
4. Добавьте строки и времена старта `мм:сс`.
5. Нажмите «Сгенерировать видео» и выберите путь сохранения.
