# Lyrics Video Generator

Desktop GUI-приложение (PySide6) для генерации lyric-video по аудиотреку.

## Что поддерживается сейчас

- Две ориентации видео: `9:16` (vertical) и `16:9` (horizontal).
- Два render-режима для каждой ориентации:
  - Preview: `540x960` / `960x540`, `24 fps`.
  - Final: `1080x1920` / `1920x1080`, `30 fps`.
- Два режима синхронизации текста:
  - Ручной (таблица `мм:сс + строка`).
  - Автоматический (анализ аудио + полный текст трека, затем автозаполнение таблицы с ручной правкой).
- Два режима фона:
  - `Мягкий градиент` (MVP-режим).
  - `Динамический BPM-фон` (реакция на beat, мягкие размытые вспышки по палитре).
- NVENC с fallback на `libx264`.
- Streaming/chunked render (многопоточная генерация кадров с pipe в ffmpeg).

## Структура

- `gui/main_window.py` — GUI: ориентация, режим синхронизации, авто-синхронизация, режим фона.
- `models/project.py` — расширенные модели проекта и render profiles.
- `core/layout.py` — адаптивный layout для vertical/horizontal.
- `core/auto_sync.py` — авто-синхронизация lyrics (baseline на `librosa`).
- `core/audio_analysis.py` — BPM/beat-анализ для динамического фона.
- `core/background.py` — стратегии генерации фона (`soft_gradient`, `bpm_dynamic`).
- `core/render.py` — общий render pipeline + логика fallback.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Также в системе должны быть установлены `ffmpeg` и `ffprobe`.

## Использование GUI

1. Выберите аудио и обложку.
2. Заполните метаданные.
3. Выберите режим синхронизации:
   - **Ручная**: заполняйте таблицу вручную.
   - **Автоматическая**: вставьте/загрузите полный текст трека, нажмите «Синхронизировать автоматически», затем при необходимости подправьте таблицу.
4. Выберите ориентацию видео (`Вертикальное` / `Горизонтальное`).
5. Выберите режим фона (`Мягкий градиент` / `Динамический BPM-фон`).
6. Выберите render-режим (Preview/Final) и запустите экспорт.

## Ограничения и ожидания качества

### Авто-синхронизация

- Это **usable baseline**, а не идеальный forced alignment.
- Лучше всего работает на треках с различимым вокалом.
- При плотной обработке вокала, шумном миксе, экстремальных вокальных техниках точность снижается.
- После автоанализа таблица остаётся редактируемой (рекомендуется ручная доводка).

### BPM-анализ и динамический фон

- Beat detection выполняется один раз перед рендером.
- При слабом результате анализатора применяется fallback-поведение (в логах есть предупреждения).
- Эффект сделан мягким и атмосферным (без агрессивного строба), но сложность сцены всё равно может замедлить рендер.

## Производительность

- Схема streaming/chunked render сохранена.
- Более тяжёлые режимы (`Final`, `Horizontal`, `bpm_dynamic`) могут рендериться дольше — это логируется.
- Для контроля скорости используйте настройки потоков и размера чанка в GUI.

## Логи

В консоль логируются ключевые этапы:
- выбранная ориентация, render profile, разрешение;
- выбранный режим синхронизации и фона;
- параметры layout;
- BPM/beat-метрики;
- fallback-сценарии (NVENC/CUDA/beat-analysis);
- прогресс генерации.
